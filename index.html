Experience

[JOB TITLE] · [COMPANY]

Realtime backends for online casino and arcade games — slots, fish shooting, card games and casual multiplayer — on a shared Node.js framework serving raw TCP, WebSocket and WSS from one clustered process per game.

  • Cut a hot-path lookup from milliseconds to tens of microseconds by moving read-only reference data out of the database into a local embedded store — generated from the live schema, so it is rebuilt rather than maintained by hand.
  • Built simulation tooling that validates game maths over millions of runs and reports automatically, so releases are signed off on evidence rather than intuition.
  • Kept per-title modules contained: the server statically scans each one at boot and refuses to start if it reaches outside its own directory.
  • Held a production runtime pinned to Node 12 for years, with the dependency tree documented well enough that no upgrade has silently broken a live server.
